def names(tags):
    return [t.a.text if t.name == "li" else t.get_text(strip=True) for t in tags]

선택자뜻
[속성]속성이 있다
[속성="값"]값이 정확히 같다
[속성^="값"]값이 이것으로 시작한다
[속성$="값"]값이 이것으로 끝난다
[속성*="값"]값 어딘가에 들어 있다

^, $, *는 링크 주소로 거를 때 자주 쓴다. 예를 들어 a[href^="item/"]은 상품 상세 링크만, a[href$=".pdf"]는 PDF 링크만 고른다.

선택자뜻

:not(선택자)그 선택자에 맞지 않는 것

주의할 점: h2:nth-child(2)는 “두 번째 h2”가 아니라 “부모의 두 번째 자식인데 그게 h2인 것”이다. div#menu의 자식은 h2, ul, h2, ul 순서라 두 번째 자식은 ul이고, 결과가 빈 리스트다. 같은 태그끼리의 순서를 원하면 :nth-of-type(2)를 쓴다.

import requests
from bs4 import BeautifulSoup

url = "https://tae62jj021216.github.io/assets/crawl/shop/list-1.html"
soup = BeautifulSoup(requests.get(url, timeout=5).text, "html.parser")

def won(text):
    return int(text.replace(",", "").replace("원", ""))

for li in soup.select("li.product"):
    name = li.select_one(".name a").text
    regular = won(li.select_one(".price .regular").text)
    sale_tag = li.select_one(".price .sale")
    sale = won(sale_tag.text) if sale_tag else None
    print(li["data-id"], name, regular, sale)

복습 문제

메뉴판 HTML(soup)을 쓴다.

  1. 커피 메뉴 중 품절이 아닌 메뉴의 이름을 select 한 번으로 구하시오. 결과는 ['아메리카노', '카페라테'].
  2. 링크 주소가 /menu/b로 시작하는 메뉴의 이름을 구하는 선택자를 쓰시오.
  3. 다음 두 선택자의 결과 개수가 다른 이유를 쓰시오.
    #menu ul / #menu > li
  4. 두 번째 ul(디저트)의 첫 메뉴 이름을 :nth-of-type을 써서 구하시오.
정답과 해설
  1. [li.a.text for li in soup.select("ul.coffee li:not(.soldout)")]
  2. soup.select('a[href^="/menu/b"]') → ['초코 브라우니']
  3. #menu ul은 div#menu 안 어딘가의 ul이라 2개다. #menu > li는 div#menu 바로 아래의 li를 찾는데, li는 ul 아래에 있어 0개다.
  4. soup.select_one("#menu ul:nth-of-type(2) li").a.text → '버터 쿠키'
