[Python] 02. 자료형, 형변환, 그리고 input()/eval()

지난번에 변수랑 리터럴을 봤으니까, 오늘은 그 값들이 실제로 어떤 자료형으로 분류되는지랑 자료형끼리 서로 바꾸는 형변환을 정리했다. 사용자 입력 받는 input()도 같이 묶었다.

파이썬 기본 자료형

파이썬이 기본 제공하는 자료형(built-in type)이 생각보다 많다.

자료형의미예시
bool논리값True, False
int정수123
float실수123.5, 1e-5
complex복소수5+3j
str문자열'hi', "banana"
bytes0~255 사이 코드 모음b'apple'
list순서 있는 객체 모음, 변경 가능[1, 2, 3]
dict키-값 쌍의 모음{'name': 'Hong'}
tuple순서 있는 객체 모음, 변경 불가(1, 2, 3)
set중복 불가한 집합{1, 2, 3}

지금까진 int, float, str, bool 정도만 썼는데 뒤로 갈수록 list/dict/tuple/set을 훨씬 많이 쓸 것 같은 느낌이다.

파이썬 변수는 자료형을 미리 정하지 않고 저장한 값에 따라 자료형이 정해진다(동적 타이핑). type()으로 확인 가능.

1
2
3
4

a = 100
print(type(a))   # <class 'int'>
a = 'hello'
print(type(a))   # <class 'str'>

진법 변환

정수를 2진수/8진수/16진수 문자열로 바꿔주는 함수들.

1
2
3

print(bin(11))   # 2진수로
print(oct(11))   # 8진수로
print(hex(11))   # 16진수로

0b, 0o, 0x로 시작하는 리터럴은 각각 2/8/16진수를 코드에 바로 쓸 수 있게 해준다. 0x11은 16진수로 11(십진수 17)이라는 뜻.

형변환

자료형을 바꾸는 함수들도 자주 쓴다.

1
2
3
4

age = '40'
weight = '65.5'
print('10년 뒤 나이는?', int(age) + 10)
print(f'체중 10kg 감량 시 {float(weight) - 10}kg')

int(문자열, base=진수)처럼 진수를 지정해서 변환하는 것도 되는데 이건 오늘 처음 알았다.

1
2

print(int('ff', base=16))     # 16진수 'ff' -> 십진수 255
print(int('101011', base=2))  # 2진수 문자열 -> 십진수

주의할 점 하나. base로 지정한 진수에 존재하지 않는 숫자가 문자열에 섞여 있으면 바로 ValueError가 난다. 2진수 문자열에 8이나 9가 들어있으면 안 된다는 얘기.

input()으로 값 받기

input()은 값을 무조건 문자열로 돌려준다는 게 핵심이다. 숫자 계산을 하려면 int()나 float()로 형변환 필수.

1
2
3

num1 = int(input('정수1: '))
num2 = int(input('정수2: '))
print(f'{num1}+{num2}={num1 + num2}')

BMI 계산기 짜보니까 왜 형변환을 배우는지 바로 와닿았다.

1
2
3
4
5

weight = float(input('몸무게(kg) : '))
height = float(input('키(cm) : ')) / 100
print(f'당신의 BMI는 : {weight / height**2:.2f}')

# 저체중 18.5미만 / 정상 18.5~22.9 / 과체중 23~24.9 / 비만 25.0이상 / 고도비만 30.0이상

eval()

eval()은 문자열로 된 수식을 진짜로 계산해서 값을 돌려준다.

1
2

text = '3+10'
print(eval(text))   # 13

input()이랑 같이 쓰면 형변환 없이 바로 숫자 계산이 되니까 편해 보이는데, 사용자가 입력한 문자열을 그대로 실행해버리는 구조라 실제 서비스에서는 위험할 수 있다고 한다. 연습용으론 편해도 나중엔 조심해서 써야 할 함수로 기억해두려고.

input()의 반환값이 무조건 문자열이라는 걸 자꾸 까먹는다. 숫자 계산 전엔 형변환부터 확인하는 습관을 들여야 할 듯. int(문자열, base=n) 방식도 처음 본 개념이라 따로 적어둔다.

복습 문제.

  1. 다음 중 맞는 설명을 모두 고르시오. ① type()은 값이 어떤 자료형인지 알려준다. ② input()으로 25를 입력받으면 그 값은 int다. ③ tuple은 만든 뒤에 안의 값을 바꿀 수 없다. ④ 정수를 담았던 변수에 나중에 문자열을 다시 담을 수 있다. ⑤ set에 같은 값을 여러 번 넣어도 하나만 남는다.
