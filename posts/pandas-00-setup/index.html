[Pandas] 00. 실습 환경과 예제 데이터

pandas는 표 형태의 데이터를 파이썬으로 읽고, 고르고, 고치고, 합치고, 요약하는 라이브러리다. 이 시리즈의 예제는 모두 DB 시리즈에서 쓴 가상 카페 체인 cafedb를 CSV로 꺼낸 데이터를 쓴다. 같은 데이터라서 SQL로 풀던 질문을 pandas로 다시 풀어 볼 수 있다.

시리즈 구성

부편다루는 내용

2부 파악과 정제04~08데이터 파악·정렬·순위, 결측치와 중복, 형 변환·문자열·범주화, 날짜와 시계열, apply와 map

pandas 3.0(2026년 1월 출시)은 2.x와 동작이 다른 곳이 있다. 문자열 열의 기본 자료형이 object에서 str로 바뀌었고, 복사본을 고치면 원본이 바뀌지 않는 규칙(Copy-on-Write)이 기본이 됐다. 검색해서 찾은 예전 코드가 다르게 동작하는 곳은 각 편에 표시했다.

파일 구성

앞의 8개는 DB 시리즈의 cafedb 테이블과 내용이 같다. 뒤의 2개는 pandas 전처리와 시계열을 연습하려고 같은 카페 체인 설정으로 새로 만든 파일이다.

파일내용주요 열주로 쓰는 편
category.csv메뉴 분류 (음료 > 커피 > 에스프레소 …)category_id, name, parent_id본문에서는 쓰지 않음 (DB 시리즈와 같은 구성)
menu.csv메뉴와 가격menu_id, name, category_id, price, is_seasonal, released_on1~4, 6, 8, 9, 11~13

orders.csv주문 12건 (member_id가 빈칸이면 비회원)order_id, member_id, store, ordered_at7, 9, 11, 12

event_2025.csv, event_2026.csv연도별 이벤트 참가자member_id, name, prize9

daily_sales.csv세 지점의 2026년 8월 일별 판매 잔 수와 매출date, store, cups, revenue7, 10~13

테이블 사이의 관계는 DB 시리즈와 같다. menu.category_id는 category를, orders.member_id는 member를, order_item의 order_id·menu_id는 orders·menu를 가리킨다. 그림은 DB 00편의 ERD를 보면 된다.

orders.csv는 예제용으로 고른 회원 앱 주문 12건이고, daily_sales.csv는 지점 계산대에서 집계한 하루 합계라서 둘의 숫자는 서로 맞지 않는다. 데이터는 모두 가상이다.

복습 문제

  1. cafe 폴더를 작업 폴더가 아닌 다른 곳에 두었더니 pd.read_csv("cafe/menu.csv")에서 FileNotFoundError가 났다. 고치는 방법 두 가지를 쓰시오.
  2. display.unicode.east_asian_width 설정을 켜고 끌 때 달라지는 것과 달라지지 않는 것을 하나씩 쓰시오.
  3. orders.csv와 orders_raw.csv는 같은 주문을 담고 있다. orders_raw.csv의 행 수가 더 많은 이유를 파일 구성 표를 보고 두 가지 쓰시오.
정답과 해설

1. 상대 경로 cafe/menu.csv는 현재 작업 폴더를 기준으로 찾는다. ① cafe 폴더를 노트북(또는 .py) 파일과 같은 폴더로 옮기거나, ② pd.read_csv(r"D:\data\cafe\menu.csv")처럼 전체 경로를 쓴다. 노트북에서는 import os; print(os.getcwd())로 작업 폴더를 확인할 수 있다.

2. 달라지는 것은 출력할 때 한글 열의 정렬(폭 계산)이다. 데이터 값, 행·열 수, 자료형은 달라지지 않는다.

3. orders.csv는 주문 한 건이 한 행이지만 orders_raw.csv는 주문 상세 한 줄이 한 행이라 메뉴를 두 개 시킨 주문은 두 행이 된다(19행). 여기에 같은 줄이 두 번 들어온 중복 행 2개가 더해져 21행이다.
