Claude Code 개발 환경 프로젝트 소개

Claude Code 세션은 새로 열거나 /clear로 비우면 앞의 대화를 기억하지 않는다. 대화가 길어지면 자동으로 압축되면서 세부도 줄어든다. 졸업 작품, 공모전, 이 블로그를 여러 세션에서 나눠 진행하면서, 세션이 바뀌어도 작업이 이어지는 환경을 만들었다.

문제

필요한 것은 세 가지였다.

필요한 것구체적으로
이어받기새 세션이 앞 세션의 목표, 한 일, 남은 일, 결정을 바로 알아야 한다
기억 공유결정의 근거, 실패한 방법, 공통 규칙을 세션과 프로젝트를 넘어 다시 꺼내 쓸 수 있어야 한다
실수 막기원본 자료를 고치거나, 다른 세션의 변경까지 커밋하는 일을 막아야 한다

세 번째가 따로 필요한 이유는 지침 파일(CLAUDE.md)에 “하지 말 것”을 적어 두어도 지켜지지 않은 일이 있었기 때문이다. 회고에서 자세히 쓴다.

역할

개인 프로젝트다. 구조를 정하고, 규칙과 결정을 내리고, 새 세션을 열어 실제로 동작하는지 확인했다. hook 스크립트와 스킬 파일의 작성은 Claude Code와 함께 했다.

기술 스택

분류사용한 것
에이전트Claude Code (데스크톱 앱). hook과 스킬로 동작을 넓혔다
기억 저장소Obsidian 볼트 (마크다운 위키)
hook 스크립트PowerShell 5.1, Python
이력·백업Git, GitHub 비공개 저장소
사용량 대시보드AgentPulse Windows 포트 (오픈소스 macOS 앱을 옮김. C# 수집기와 로컬 웹 화면)

구성

위키

모든 세션이 같이 쓰는 Obsidian 볼트 하나를 기억 저장소로 둔다. 프로젝트마다 폴더 하나에 허브 문서, 결정/, 교훈/, 자료정리/, 산출물/을 모은다. 아무것이나 저장하지 않도록 저장 필터 다섯 가지를 두었다.

  1. 앞으로 다시 쓸 정보인가
  2. 다른 세션이 이어받으려면 꼭 읽어야 하는가
  3. 결정의 근거와 결정한 사람을 나중에 추적해야 하는가
  4. 다시 하면 안 되는 실패인가
  5. 모두가 맞춰야 하는 공통 규칙인가

하나도 해당하지 않으면 저장하지 않는다. 바뀐 내용은 커밋할 때마다 비공개 저장소로 push해 백업한다.

스킬

말로 부르면 정해진 절차를 따르는 스킬을 만들었다.

이렇게 말하면하는 일
“인수인계 남겨줘”목표, 한 일, 남은 일, 결정, 사용자 선호를 인수인계 노트로 저장한다
“옵시디언에 저장해줘”저장 필터를 통과한 것만 위키에 저장하고 커밋한다
“옵시디언 참조해줘”위키에서 찾아 근거 링크와 함께 답한다. 없으면 없다고 한다
“위키 점검해줘”깨진 링크, 중복, 근거 없는 내용을 찾아 보고만 한다

hook

hook은 Claude Code가 특정 시점에 자동으로 실행하는 스크립트다. 모델의 판단이 아니라 스크립트가 동작하므로 매번 같게 움직인다.

시점하는 일
세션 시작같은 작업 폴더의 최근 인수인계 노트(48시간 이내, 진행 중, 1건)를 세션에 붙인다
압축 직전그때까지의 요청과 답변을 위키의 자동 백업 폴더에 남긴다
도구 실행 직전원본 자료 수정, 작업 기록의 지난 줄 변경을 막는다. 변경을 통째로 담는 git 명령은 확인을 받는다
파일 수정 뒤Claude 설정 파일을 고치면 그 파일만 설정 저장소에 커밋·push한다

대시보드

AgentPulse는 macOS 메뉴 막대에서 도는 오픈소스 앱이다. 이것을 Claude Code 전용 Windows 로컬 웹 대시보드로 옮기고, 대화 창이 80% 넘게 차면 “/handoff 후 /clear 권장” 알림을 띄우게 했다. 알림을 보고 인수인계를 남긴 뒤 비우면, 새 세션에 그 노트가 자동으로 붙는다.

결과

새 세션을 열어 하나씩 확인했다.

확인한 것날짜결과
인수인계 자동 복원9/19/clear 뒤 새 세션에 인수인계 노트가 붙었다. 참조·저장·점검도 같은 날 새 세션에서 확인
압축 직전 백업9/28실제 작업 중 자동 압축이 일어났고 백업 파일이 생겼다
보호 hook9/30작업 기록 첫 줄을 고치려는 시도가 실행 전에 거부됐다. 파이프 시험 23건 통과
git 전부 담기 확인 hook9/30파이프 시험 25건 통과
저장 필터10/1“오늘 점심이 맛있었다, 저장해줘”에 다섯 필터를 모두 ✗로 판정하고 저장하지 않았다
경로별 규칙 자동 로드10/1특정 폴더 파일을 읽을 때만 세부 규칙 파일이 붙었다

이 글을 쓰는 세션도 시작할 때 이전 세션의 인수인계 노트가 자동으로 붙어 있었다.
