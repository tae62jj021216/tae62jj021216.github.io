[DB] 00. 실습 환경과 예제 DB

데이터베이스 시리즈를 시작하며, 글에 나오는 예제를 직접 실행해 볼 수 있도록 실습 환경과 예제 DB를 정리한다. 이 시리즈의 모든 예제는 여기서 만드는 가상의 카페 체인 DB cafedb를 쓴다.

시리즈 구성

부편다루는 내용
준비00실습 환경과 예제 DB (이 글)
1부 기초01~03데이터베이스와 DBMS, 3단계 스키마, 관계 모델과 키
2부 설계04~07ER 모델, ER→테이블 변환, 정규화
3부 SQL08~19DDL·DCL·DML, SELECT, 집계, 집합 연산, JOIN, 서브쿼리, CTE, 함수
4부 심화20~22뷰, 트랜잭션과 동시성 제어, 관계대수

1부와 2부는 이론 중심이라 SQL을 몰라도 결과만 보면 이해할 수 있게 썼고, SQL 문법은 8편부터 차례로 다룬다.

실습 환경

  • DBMS: MySQL 8.4 LTS에서 모든 예제를 실행해 확인했다. INTERSECT·EXCEPT(14편)를 쓰려면 8.0.31 이상이 필요하다.
  • 설치: MySQL 공식 사이트에서 MySQL Community Server를 받아 설치한다. 명령줄 클라이언트(mysql)나 MySQL Workbench 중 편한 것을 쓰면 된다.

정보처리기사·SQLD 시험은 표준 SQL(일부 Oracle 문법) 기준이다. MySQL과 문법이 다른 곳은 각 편에 따로 표시했다.

테이블 구성

테이블내용주요 열예제에서 쓰는 곳
category메뉴 분류 (음료 > 커피 > 에스프레소 …)category_id, name, parent_id계층 구조, 재귀 CTE
menu메뉴와 가격menu_id, name, category_id, price, is_seasonal, released_on조건 검색, 정렬, 집계
member회원member_id, name, grade, city, phone, joined_on, referrer_idNULL 처리(phone, city), 셀프 조인(추천인)
orders주문order_id, member_id, store, ordered_at비회원 주문(member_id가 NULL)과 외부 조인
order_item주문 상세order_id, menu_id, qty (복합 기본키)다대다 관계, 조인, 집계
staff직원staff_id, name, role, store, manager_id, salary셀프 조인·재귀 CTE(조직도), 순위 함수
event_2025, event_2026연도별 이벤트 참가자member_id, name, prize집합 연산

테이블 사이의 관계는 다음과 같다.

  • menu.category_id → category, category.parent_id → category(자기 참조)
  • orders.member_id → member (NULL이면 비회원 주문)
  • order_item.order_id → orders(주문을 지우면 상세도 함께 삭제), order_item.menu_id → menu
  • member.referrer_id → member, staff.manager_id → staff(자기 참조)

데이터는 모두 가상이다. 회원과 직원 이름은 고전 소설 속 인물에서 따왔다.

데이터를 바꾸는 예제는 연습 DB에서

INSERT·UPDATE·ALTER처럼 데이터나 구조를 바꾸는 예제는 cafedb를 그대로 두고 연습 DB cafe_practice에서 실행한다. 해당 편 첫머리의 “실습 준비 SQL”을 펼쳐 실행하면 그 편에 필요한 cafe_practice가 새로 만들어지고, 이어서 본문 SQL을 순서대로 실행하면 글과 같은 결과가 나온다.

실습하다가 cafedb가 바뀌었다면 cafedb.sql을 다시 실행해 처음 상태로 되돌리면 된다.
