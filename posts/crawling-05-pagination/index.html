[크롤링] 05. 정적 크롤링 ① 목록과 페이지 넘기기

연습 쇼핑몰의 상품 30개는 목록 4페이지에 나뉘어 있다. 이 글에서는 페이지를 차례로 돌며 상품마다 이름·가격·할인율·평점을 꺼내 표(DataFrame)로 만들고 CSV로 저장한다.

2~4편의 requests와 BeautifulSoup을 이어서 쓴다. 표는 pandas로 만든다(pip install pandas). 결과는 Python 3.12, pandas 3.0에서 확인했다.

순서

  1. 몇 페이지까지 있는지 알아낸다.
  2. 상품 하나(li.product)를 딕셔너리 하나로 바꾸는 함수를 만든다.
  3. 페이지마다 요청 → 상품 목록 → 딕셔너리 리스트에 더한다. 요청 사이에 쉰다.
  4. 리스트를 DataFrame으로 바꾸고, 개수와 값을 확인한 뒤 CSV로 저장한다.

import time
import pandas as pd
import requests
from bs4 import BeautifulSoup

BASE_URL = "https://tae62jj021216.github.io/assets/crawl/shop/"
HEADERS = {"User-Agent": "Mozilla/5.0 (study crawler)"}

def get_soup(url):
    r = requests.get(url, headers=HEADERS, timeout=5)
    r.raise_for_status()               # 404 등이면 여기서 멈춘다
    return BeautifulSoup(r.text, "html.parser")

def won(text):
    return int(text.replace(",", "").replace("원", ""))

def parse_product(li):
    sale = li.select_one(".price .sale")
    pct = li.select_one(".price .pct")
    rating_text = li.select_one(".rating").get_text(" ", strip=True)   # '★ 4.5 (49)'
    return {
        "id": li["data-id"],
        "name": li.select_one(".name a").text,
        "category": li["data-category"],
        "price": won(li.select_one(".price .regular").text),
        "sale_price": won(sale.text) if sale else None,
        "discount": int(pct.text.rstrip("%")) if pct else 0,
        "soldout": "soldout" in li["class"],
        "rating": float(rating_text.split()[1]),
        "reviews": int(li.select_one(".rating .count").text.strip("()")),
    }

print(parse_product(soup.select_one("li.product")))

1

{'id': 'p001', 'name': '에티오피아 예가체프 200g', 'category': '원두', 'price': 18000, 'sale_price': 15300, 'discount': 15, 'soldout': False, 'rating': 4.5, 'reviews': 49}
  • 세일가와 할인율은 없는 상품이 있다. 없으면 None·0을 넣는다.
  • 평점 ★ 4.5 (49)는 공백으로 나눠 두 번째 조각을 float로, 리뷰 수는 .count 태그에서 괄호를 떼어 int로 바꿨다.
  • 글자를 숫자로 바꾸는 일은 꺼낼 때 바로 한다. 나중에 표에서 정렬·평균을 낼 수 있다.

상품 하나를 처리하는 함수를 먼저 만들고 한 개로 시험한 뒤 반복문에 넣으면, 틀린 곳을 찾기 쉽다.

  • index=False: 0, 1, 2… 행 번호를 파일에 쓰지 않는다.
  • encoding="utf-8-sig": 파일 앞에 UTF-8 표시(BOM)를 붙인다. 이것이 없으면 엑셀에서 열 때 한글이 깨진다.
  • 다시 읽으면 sale_price는 또 float64다. CSV에는 자료형이 저장되지 않으므로, 읽은 뒤 필요하면 다시 바꾼다.

다른 방법: “다음” 링크 따라가기

마지막 페이지 번호가 없는 사이트도 있다. 그때는 “다음” 링크가 없어질 때까지 따라간다.

from urllib.parse import urljoin

url = BASE_URL + "list-1.html"
visited = []
while url:
    soup = get_soup(url)
    visited.append(url.rsplit("/", 1)[1])
    nxt = soup.select_one(".paging a.next")
    url = urljoin(url, nxt["href"]) if nxt else None
    time.sleep(1)
print(visited)

1

['list-1.html', 'list-2.html', 'list-3.html', 'list-4.html']

마지막 페이지에는 a.next가 없어 None이 되고, url이 None이 되어 반복이 끝난다. urljoin은 현재 페이지 주소를 기준으로 상대 주소(list-2.html)를 완전한 주소로 바꿔 준다. 6편에서 자세히 다룬다.

방법장점단점
마지막 번호로 주소 목록 만들기전체 페이지 수를 먼저 알 수 있다번호가 주소에 드러나야 한다
“다음” 링크 따라가기주소 규칙을 몰라도 된다링크 구조가 바뀌면 멈추거나, 잘못하면 끝없이 돈다

주의할 점: while 반복은 종료 조건이 틀리면 끝나지 않는다. 방문한 주소를 집합에 넣어 같은 주소가 다시 나오면 멈추거나, 최대 페이지 수를 정해 두면 안전하다.

복습 문제

이 글의 df(30행)를 쓴다.

  1. sale_price 열이 float64가 된 이유와, 정수로 보이게 바꾸는 코드를 쓰시오.
  2. 원두 중 세일하는 상품의 이름과 세일가를 구하는 코드를 쓰시오. 4개가 나와야 한다.
  3. 리뷰 수가 가장 많은 상품의 이름을 구하시오.
  4. 마지막 페이지 링크의 href가 list-12.html일 때, 페이지 번호 12를 정수로 꺼내는 코드를 쓰시오.
  5. CSV를 엑셀로 열었더니 한글이 깨졌다. to_csv에서 무엇을 바꾸는가?
정답과 해설
  1. 세일가가 없는 상품의 None이 NaN(실수)으로 바뀌어, pandas가 열 전체를 실수로 만들었다. df["sale_price"] = df["sale_price"].astype("Int64")
  2. 1

    df.loc[(df["category"] == "원두") & df["sale_price"].notna(), ["name", "sale_price"]]

    에티오피아 예가체프, 과테말라 안티구아, 브라질 산토스, 하우스 블렌드.

  3. df.loc[df["reviews"].idxmax(), "name"] → '브라질 산토스 200g'(197개)
  4. int("list-12.html".removeprefix("list-").removesuffix(".html")) → 12
  5. encoding="utf-8-sig"로 저장한다.
