리스트 다음은 튜플이다. 처음엔 그냥 수정 안 되는 리스트 아닌가 싶었는데, 정리하다 보니 튜플만의 쓰임새가 꽤 명확해서 그 부분 위주로 적어본다.

튜플이란

리스트와 유사한 시퀀스 자료형이지만, 요소 추가/수정/삭제가 불가능하다(immutable). 읽기 전용 데이터를 다룰 때 쓰기 위해 존재하는 자료형이라고 이해했다. 소괄호 () 또는 tuple() 함수로 생성하고, 요소 접근은 리스트처럼 인덱스 []를 쓴다.

t1 = (1, 2, 3)
t2 = 4, 5, 6                 # 괄호 없이도 튜플이 된다
t3 = t1, (6, 7, 8)           # 튜플 안에 튜플
t4 = [1, 2], [3, 4]          # 리스트를 담은 튜플도 가능
t5 = tuple([5, 6, 7, 8])     # 리스트 -> 튜플 변환
t6 = tuple('python')         # 문자열의 문자 하나하나가 요소로
t7 = tuple()                 # 빈 튜플

print(t1, type(t1))
print(t6, type(t6))          # ('p', 'y', 't', 'h', 'o', 'n')

괄호 없이 4, 5, 6만 써도 튜플이 된다는 게 신기했다. 결국 튜플을 만드는 건 괄호가 아니라 쉼표라는 걸 알게 됐다.

t = 'apple', 'banana', 'berry', 'melon'

for i in range(len(t)):
    print(t[i])

print(t[1:])       # 슬라이싱
print(t[::2])      # 짝수 인덱스만

# 연결 : +
t1 = (3, 4, 5)
t2 = 10, 11, 1

print(t3)           # (3, 4, 5, 10, 11, 1)

# 반복 : *
t1 = ('Hi',)         # 요소가 1개인 튜플은 쉼표를 꼭 붙여야 한다!
print(t1 * 10)

# 멤버 확인 : in / not in
t = 'apple', 'banana', 'berry', 'melon'
print('kiwi' in t)        # False
print('berry' in t)       # True

여기서 하나 실수할 뻔했던 게, t1 = ('Hi')처럼 쉼표 없이 쓰면 이건 튜플이 아니라 그냥 문자열이 된다는 점이다. 요소가 하나뿐인 튜플을 만들 때는 ('Hi',)처럼 쉼표를 반드시 붙여야 한다.

패킹(packing)과 언패킹(unpacking)

패킹은 여러 개의 데이터를 하나의 튜플에 담는 것, 언패킹은 튜플에 담긴 데이터를 각각의 변수로 꺼내오는 것이다.

# a, b = t
# ValueError: too many values to unpack (expected 2)

a, *b = t
print(a)   # 1
print(b)   # [2, 3, 4, 5]  <- *b는 리스트로 받아진다

*a, b = t
print(a)   # [1, 2, 3, 4]
print(b)   # 5

a, *b, c = t
print(a, b, c)   # 1 [2, 3, 4] 5

a, b, *c = t
print(a, b, c)   # 1 2 [3, 4, 5]

# a, *b, *c = t
# 문법 오류 - *는 한 번만 쓸 수 있다

변수 개수와 튜플 길이가 안 맞으면 그냥 에러가 난다는 걸 처음 알았는데, *변수를 쓰면 나머지 전부를 리스트로 몰아서 받아준다는 게 꽤 편리했다. 단, *는 언패킹 한 번에 하나만 쓸 수 있다는 제약이 있다.

결국 튜플 자체를 직접 바꾸는 게 아니라, 새 튜플을 만들어서 덮어쓰는 방식이라는 공통점이 있었다. 불변이라는 성질은 절대 깨지지 않는구나 싶었다.

그럼 수정도 안 되는 자료형을 왜 굳이 쓰나 싶었는데, 쓰임새를 생각해보니 크게 두 갈래였다. 하나는 바뀌면 안 되는 값을 묶어 둘 때다. 화면 해상도 (1920, 1080)처럼 한 번 정하면 그대로여야 하는 값은 튜플로 두면 실수로 바꿀 일이 없다. 불변이라 딕셔너리 키도 될 수 있어서, seat = {(3, 5): '예약됨'}처럼 (행, 열) 좌표를 키로 쓰는 것도 가능하다. 다른 하나는 여러 값을 한 번에 주고받을 때다.

def summary(scores):
    total = sum(scores)
    return total, total / len(scores)   # 괄호가 없어도 튜플로 묶여서 돌아온다

result = summary([80, 90, 70])
print(result)       # (240, 80.0)

total, avg = summary([80, 90, 70])     # 받자마자 언패킹
print(total, avg)   # 240 80.0

실수로 값이 바뀌면 안 되는 곳에는 리스트 대신 튜플을 쓰는 게 안전하다.

요소가 1개인 튜플은 (값,)처럼 쉼표를 꼭 붙여야 튜플로 인식된다는 것(('Hi')는 그냥 문자열), 확장 언패킹에서 *b로 받은 부분은 리스트가 된다는 것, 그리고 튜플 자체는 수정 못 해도 튜플 안에 리스트가 들어있으면 그 리스트 내부는 수정 가능하다는 것(예: t4 = [1, 2], [3, 4]에서 t4[0].append(3)은 가능)까지가 오늘 새로 챙긴 부분들이다.
