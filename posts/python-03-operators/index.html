[Python] 03. 산술/비교/논리/비트 연산자와 우선순위

오늘은 연산자. 산술 연산자는 익숙한데 비트 연산자랑 우선순위 표는 처음이라 좀 외울 게 있었다.

산술 연산자

+, -, *, /는 다 아는 거고, 눈여겨볼 건 %(나머지), //(몫), **(거듭제곱).

1
2
3
4
5
6

num1, num2 = 10, 3
print(f'{num1}+{num2}={num1+num2}')
print(f'{num1}/{num2}={num1/num2:.3f}')     # 나누기는 항상 float
print(f'나머지={num1 % num2}')               # 1
print(f'몫={num1 // num2}')                  # 3
print(f'거듭제곱={num1 ** num2}')            # 1000

/는 결과가 항상 실수로 나온다는 걸 다시 확인했다. 10/3처럼 안 나눠떨어질 때뿐 아니라 10/5처럼 나눠떨어져도 2.0으로 나온다.

초 단위를 분/초로 바꾸는 문제도 풀어봤다.

1
2

sec = 10000
print(f'{sec // 60}분 {sec % 60}초')   # 166분 40초

//랑 %를 같이 쓰면 동전 개수 계산 같은 “몇 개씩 나누고 남은 건 얼마” 문제에 그대로 쓸 수 있다.

복합 대입 연산자도 있다. +=, -=, *=, /=, **=, %=, //= 전부 자기 자신에 연산해서 다시 저장하는 축약형.

1
2

a = 10
a += 10   # a = a + 10 과 동일

비교 연산자

두 값을 비교해서 True/False를 돌려준다. ==(같다)랑 =(대입)를 헷갈리지 않는 게 제일 중요할 듯.

1
2
3
4
5

print(100 > 10)     # True

x = 200
y = 200
print(x == y)        # True

논리 연산자

and, or, not 세 개.

1
2
3
4

a = 15
print(a >= 10 and a <= 20)        # 둘 다 참이어야 True
print(a % 3 == 0 or a % 5 == 0)   # 둘 중 하나만 참이어도 True
print(not (a == 100))             # 부정

and는 둘 다 참이어야 하고 or는 하나만 참이어도 되는 건 익숙한데, “or은 두 값이 모두 거짓인 경우만 거짓”이라는 설명을 보고 처음엔 잠깐 헷갈렸다. 결국 같은 말인데 반대로 설명하니까. 그냥 and는 전부 참, or는 하나라도 참이면 참으로 외우기로.

비트 연산자

정수를 2진수로 바꿔서 비트 단위로 연산하는 것들. 이번 내용 중에 제일 낯설었다.

1
2
3
4
5
6

num1, num2 = 10, 7
print(bin(num1), bin(num2))
print(num1 & num2)   # AND: 둘 다 1인 자리만 1
print(num1 | num2)   # OR: 한쪽만 1이어도 1
print(num1 ^ num2)   # XOR: 다르면 1, 같으면 0
print(~num1)         # NOT: 비트 반전 (2의 보수라 부호가 바뀜)

시프트 연산자는 비트를 왼쪽/오른쪽으로 밀어서 곱셈/나눗셈 효과를 낸다.

1
2
3
4

num = 20
print(num << 1)   # 20 * 2^1 = 40
print(num << 2)   # 20 * 2^2 = 80
print(num >> 1)   # 20 / 2^1 = 10

<<가 왜 곱셈 효과를 내는지는 2진수를 손으로 옮겨 적어보고 나서야 감이 왔다. 20(10100)을 왼쪽으로 한 칸 밀면 101000, 이게 딱 40이다.

연산자 우선순위

우선순위를 한 줄로 정리해봤다(왼쪽일수록 먼저 계산). 급할 땐 그냥 괄호 치는 게 제일 안전하지만 대략은 알아두는 게 좋을 듯.

1

() > ** > 단항(+x -x ~x) > * / // % > + - > << >> > & > ^ > | > 비교(in, not in, is, is not, < <= > >= != ==) > not > and > or > if-else(조건 표현식) > lambda > :=(할당 표현식)

비교 연산자는 ==, !=까지 전부 같은 순위다. 대입 중에서 =, += 같은 건 표현식이 아니라 문장이라 이 표엔 없고, 표현식인 :=(할당 표현식, 일명 바다코끼리 연산자)만 맨 아래에 들어간다. 그리고 **는 오른쪽부터 묶이고(2 ** 3 ** 2는 2 ** 9) 단항 -보다도 먼저라서, -2**2는 4가 아니라 -4가 나온다.

산술 연산자가 시프트(<<, >>)나 &, ^, | 같은 비트 연산자보다 우선순위 높다는 게 좀 의외였다(단, 단항 ~는 예외라서 곱셈보다도 먼저 계산된다). a + b << 1처럼 섞어 쓰면 +가 먼저 계산된다는 뜻이니, 헷갈릴 것 같으면 그냥 괄호 쓰기로 했다. /는 나눠떨어져도 결과가 항상 float라는 것도 오늘 다시 챙긴 부분이고, 비트 연산자끼리도 & > ^ > | 순으로 세분화되어 있다는 걸 우선순위표 보면서 새로 알았다.

복습 문제.

  1. 다음 값들을 예측해보시오. 결과가 int로 나오는지 float로 나오는지도 같이 적어보시오.
    ① 17 // 5 ② 17 % 5 ③ 12 / 4 ④ 2 ** 2 ** 3

  2. x, y, z = 4, 6, 2일 때 다음 식의 결과를 예측해보시오. 헷갈리면 괄호를 직접 쳐보면서 풀어볼 것.
    ① x + y // z * 3 ② (x + y) % z ** 2 ③ -z ** 2 + x ④ x > 3 and not y < 5 or z == 0

  3. p, q = 12, 10일 때 다음 결과를 10진수로 예측해보시오. &, |, ^ 세 개는 bin()으로 찍으면 어떻게 나오는지도 적어보시오.
    1
2
3
4

    print(p & q)
print(p | q)
print(p ^ q)
print(~q)
  4. 다음 코드의 결과를 예측해보시오. 마지막 줄은 괄호가 어디에 쳐진 것처럼 계산되는지도 적어보시오.

    n = 3
print(n << 4)
print((n << 4) >> 2)
