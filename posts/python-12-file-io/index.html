지금까지는 프로그램을 종료하면 데이터가 다 날아갔는데, 오늘 배운 파일 입출력으로 드디어 결과를 저장할 수 있게 됐다. 텍스트 파일부터 이진 파일, CSV까지 정리해본다.

파일 입출력의 3단계

1
2
3

1단계: 파일 열기   f = open(파일경로, 파일모드)
2단계: 파일 처리   read() / readline() / readlines() / write() / writelines()
3단계: 파일 닫기   f.close()

파일 모드는 이렇게 나뉜다.

  • 텍스트 파일: r(읽기) / w(쓰기, 덮어씀) / a(뒤에 이어쓰기), 읽기+쓰기는 r+ / w+ / a+
  • 이진 파일: rb / wb / ab (텍스트 모드에 b만 붙임)

line = f.readline()     # 딱 한 줄만 문자열로 반환

세 메서드의 차이를 반환 타입으로 정리했다. read()는 문자열 통째로, readlines()는 문자열들의 리스트, readline()은 한 줄씩. 파일을 한 줄씩 끝까지 처리하고 싶을 땐 이렇게 반복문과 조합한다.

f = open('data.txt', 'r', encoding='utf-8')
while True:
    line = f.readline()
    if not line:      # 더 읽을 줄이 없으면 빈 문자열이 반환됨
        break
    print(line)
f.close()

# 또는 readlines()로 받은 리스트를 그냥 for문으로
f = open('data.txt', 'r', encoding='utf-8')
for line in f.readlines():
    print(line.strip())   # strip()으로 줄바꿈 문자 제거
f.close()

readline()이 더 읽을 게 없을 때 None이 아니라 빈 문자열을 반환한다는 게 포인트였다. if not line으로 빈 문자열을 걸러내는 패턴을 종료 조건으로 쓴다.

f.write('안녕하세요\n둘째 줄입니다\n')

data = ['id, name, score\n', '1,홍길동,100\n', '2,김철수,90\n']
f = open('score2.txt', 'w', encoding='utf-8')
f.writelines(data)    # writelines()는 줄바꿈을 자동으로 넣어주지 않는다!
f.close()

writelines()를 쓸 때 리스트의 각 문자열 끝에 직접 \n을 넣어줘야 한다는 걸 놓쳐서 결과가 한 줄로 다 붙어 나온 적이 있다.

'w' 모드는 매번 파일을 덮어쓴다는 것도 중요하다. 기존 내용을 유지하면서 이어붙이려면 'a'(append) 모드를 써야 한다.

f = open('score3.txt', 'r')
print(f.read())   # HelloHaHaha!!!

with문, close()를 깜빡할 걱정이 없어진다

open() → 작업 → close()를 매번 쓰다 보면 close()를 빼먹는 실수가 생기기 쉬운데, with문을 쓰면 블록이 끝나는 순간 자동으로 파일이 닫힌다.

1
2
3
4
5
6

with open('score2.txt', 'w', encoding='utf-8') as f:
    f.writelines(data)
# 이 블록을 벗어나는 순간 자동으로 close() 처리됨

with open('score2.txt', 'r', encoding='utf-8') as f:
    print(f.read())

이후로는 open()을 쓸 일이 있으면 무조건 with로 감싸는 습관을 들이기로 했다. 실수의 여지가 원천적으로 사라지는 게 크다.

이진 파일, 텍스트가 아닌 파일 다루기

이미지, 동영상, 실행파일처럼 글자가 아닌 비트 단위로 의미가 있는 파일은 rb/wb 모드로 다룬다.

with open('C:/Windows/notepad.exe', 'rb') as fr:
    with open('notepad_copy.exe', 'wb') as fw:
        while True:
            data = fr.read(1)   # 1바이트씩 읽기
            if not data:
                break
            fw.write(data)

    print(test2)              # [1, 2, 3, 4]

텍스트로 변환하는 과정 없이 리스트를 리스트 그대로 저장하고 불러올 수 있다는 게 신기했다. 나중에 딕셔너리나 클래스 객체를 저장할 때도 유용할 것 같다.

import csv

# 쓰기
with open('student.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerow(['이름', '국어', '영어', '수학'])       # 한 줄 쓰기
    writer.writerow(['홍길동', 90, 95, 88])

data2 = [['이름', '국어', '영어', '수학'], ['홍길동', '90', '95', '88']]
with open('student2.csv', 'w', newline='', encoding='utf-8') as f:
    writer = csv.writer(f)
    writer.writerows(data2)    # 여러 줄을 한 번에

# 읽기
with open('student.csv', 'r', encoding='utf-8') as f:
    reader = csv.reader(f)
    next(reader)                # 헤더(첫 줄) 건너뛰기
    for row in reader:
        print(row)               # 한 줄이 리스트로 반환됨

# 딕셔너리 형태로 읽기 (헤더를 키로 자동 매핑)
with open('student.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row)   # {'이름': '홍길동', '국어': '90', ...}

csv.writer로 쓸 때 newline=''을 안 넣으면 윈도우에서 줄 사이에 빈 줄이 하나씩 더 생긴다고 해서 옵션으로 꼭 챙겼다. 그리고 csv.DictReader를 쓰면 헤더 줄이 자동으로 키가 되어서, 앞서 배운 딕셔너리 문법을 그대로 활용해 각 컬럼 값에 접근할 수 있었다.

readline()은 더 읽을 게 없으면 None이 아니라 빈 문자열을 반환한다는 것, writelines()는 줄바꿈을 자동으로 넣어주지 않으니 직접 \n을 넣어야 한다는 것, 'w' 모드는 매번 덮어쓰고 이어쓰려면 'a' 모드를 써야 한다는 것까지 오늘 정리한 내용이다. with문을 쓰면 close()를 잊어버릴 걱정이 없으니 앞으로는 무조건 with를 쓰기로 했다.
