                       "numOfRows": 10, "pageNo": 1, "totalCount": 23}}}

HTML에서 값을 뜯어내는 대신, 처음부터 데이터만 담아 돌려주는 주소가 있다. 이것을 API라 하고, 누구나 신청해 쓸 수 있게 열어 둔 것을 오픈API라 한다. 공공데이터 포털(data.go.kr)의 API들이 위와 같은 모양으로 응답한다.

이 글의 실행 예제는 공공데이터 포털 응답 모양을 흉내 낸 연습용 매장 API(/assets/crawl/api/)를 쓴다. 정적 파일이라 인증키 없이 받을 수 있고, 쪽마다 파일이 나뉘어 있다(stores-1.json ~ stores-3.json, XML도 같음). 결과는 Python 3.12, pandas 3.0에서 확인했다.

크롤링과 API

 HTML 크롤링 (2~8편)오픈API
받는 것화면용 HTML데이터만 (JSON 또는 XML)
꺼내는 방법태그·선택자로 찾기정해진 키·태그로 바로
화면이 바뀌면코드가 깨진다영향 없음 (API 명세가 바뀔 때만)
사용 조건약관·robots.txt 확인신청과 인증키, 하루 호출 수 제한

같은 데이터를 API로 제공한다면 API를 먼저 쓴다(1편 도구 고르기).

실제 오픈API를 쓰는 흐름

공공데이터 포털을 예로 들면 이렇다.

  1. 회원 가입 후 원하는 데이터의 “활용 신청”을 한다.
  2. 승인되면 마이페이지에서 인증키(serviceKey)를 받는다.
  3. 그 API의 명세(문서)에서 요청 주소, 필수 파라미터, 응답 형식, 오류 코드를 확인한다.
  4. 요청 주소에 파라미터를 붙여 GET 요청을 보낸다.

코드 모양은 다음과 같다. 주소와 파라미터 이름은 API마다 다르므로 명세를 보고 채운다.

import os
import requests

url = "https://apis.data.go.kr/<기관 코드>/<서비스 이름>/<기능 이름>"   # 명세에 적힌 주소
params = {
    "serviceKey": os.environ["DATA_GO_KR_KEY"],   # 인증키는 코드에 직접 쓰지 않는다
    "pageNo": 1,                                   # 몇 번째 쪽
    "numOfRows": 10,                               # 한 쪽에 몇 건
    # 그 밖에 API별 조건 (지역 코드, 기간 등)
}
r = requests.get(url, params=params, timeout=10)

주의할 점: 공공데이터 포털은 인증키를 “Encoding”과 “Decoding” 두 모양으로 준다. requests의 params는 값을 알아서 퍼센트 인코딩하므로(2편), 여기에 Encoding 키를 넣으면 두 번 인코딩되어 “등록되지 않은 키” 오류가 난다. params에는 Decoding 키를 넣는다. 주소 문자열에 직접 이어 붙일 때만 Encoding 키를 쓴다.

주의할 점: 인증키는 비밀번호와 같다. 코드나 노트북에 그대로 적으면 저장소·블로그에 올릴 때 함께 퍼진다. 위처럼 환경 변수(os.environ)나 git에 올리지 않는 설정 파일에 두고 읽는다.

import time
import pandas as pd

def fetch_page(page):
    r = requests.get(f"{API}/stores-{page}.json", timeout=5)
    r.raise_for_status()
    res = r.json()["response"]
    if res["header"]["resultCode"] != "00":
        raise RuntimeError(res["header"]["resultMsg"])
    return res["body"]["items"]["item"]

all_items = []
for p in range(1, pages + 1):
    got = fetch_page(p)
    all_items.extend(got)
    print(p, len(got), len(all_items))
    time.sleep(0.5)

df = pd.DataFrame(all_items)
print(df.shape)
print(df.groupby("sido").size().to_dict())
print(df.loc[df["driveThru"] == "Y", "storeNm"].tolist())

JSON의 item 하나가 딕셔너리라 리스트째 DataFrame에 넣으면 바로 표가 된다. HTML처럼 칸마다 꺼낼 필요가 없다.

실제 API라면 stores-{page}.json 대신 같은 주소에 params={"pageNo": page, ...}만 바꿔 보낸다. 연습 API는 정적 파일이라 쪽마다 파일을 나눠 두었다.

주의할 점: 실제 API는 결과 코드가 정상이 아니어도 HTTP 상태는 200인 경우가 많다. 아래 오류 응답도 상태 코드는 200이다. raise_for_status()만으로는 부족하고, 응답 안의 resultCode를 꼭 확인한다.

item 안의 태그를 모두 돌며 태그이름: 글자로 딕셔너리를 만들었다. JSON에서는 seats가 숫자 27이었지만 XML에서는 글자 '27'이다. XML은 모든 값이 글자이므로 숫자로 쓸 열은 바꿔야 한다.

주의할 점: XML을 "html.parser"로 읽으면 태그 이름이 소문자로 바뀐다. find("storeNm")은 None이 되고 find("storenm")이어야 찾힌다. BeautifulSoup도 “XML을 HTML 파서로 읽고 있다”는 XMLParsedAsHTMLWarning 경고를 낸다. API의 XML은 "xml" 파서로 읽는다.

pandas의 read_xml을 쓰면 item들을 바로 표로 만들 수 있다.

복습 문제

  1. 전체 건수가 95건이고 한 쪽에 20건씩 받으면 몇 번 요청해야 하는가? 계산 코드를 쓰시오.
  2. requests.get(url, params={"serviceKey": 키})에 Encoding 키를 넣었더니 “등록되지 않은 키” 오류가 났다. 이유는 무엇인가?
  3. 응답의 HTTP 상태가 200인데 데이터가 비어 있다. 무엇을 먼저 확인하는가?
  4. BeautifulSoup(xml, "xml").find("item")의 seats가 '27'(글자)인 이유와, find_all("item") 결과를 seats가 정수인 DataFrame으로 만드는 코드를 쓰시오.
  5. 인증키를 코드에 직접 쓰지 않는 방법을 쓰시오.
정답과 해설
  1. math.ceil(95 / 20) → 5번
  2. params가 값을 한 번 더 퍼센트 인코딩해, 이미 인코딩된 키가 두 번 인코딩되었다. Decoding 키를 넣는다.
  3. 응답 안의 결과 코드(resultCode)와 메시지(resultMsg). 공공 API는 오류도 200으로 돌려주는 경우가 많다.
  4. XML에는 자료형이 없어 모든 값이 글자다.
