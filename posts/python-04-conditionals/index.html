이번엔 조건문이다. if 자체는 다른 언어에서도 봐서 낯설지 않았는데, 파이썬 특유의 삼항연산자 표현이랑 여러 조건을 조합하는 문제들 풀면서 실수했던 부분을 정리해둔다.

기본 if / else

1
2
3
4
5

num = int(input('숫자입력: '))
if num > 0:
    print('양수')
else:
    print('음수')

여기서 주의할 점. 이 코드는 사실 0이 입력되면 “음수”로 잘못 출력된다. num > 0이 아니면 무조건 else(음수)로 빠지기 때문이다. 그래서 0까지 구분하려면 elif가 필요하다.

if ~ elif ~ else, 다중 조건

num = int(input('정수입력: '))
if num > 0:
    print('양수')
elif num < 0:
    print('음수')
else:
    print('0')

학점 계산처럼 구간이 여러 개인 문제에 elif를 줄줄이 쓰는 패턴이 자주 나온다.

score = int(input('점수입력(0~100): '))
if score >= 90:
    result = 'A'
elif score >= 80:
    result = 'B'
elif score >= 70:
    result = 'C'
elif score >= 60:
    result = 'D'
else:
    result = 'F'
print(f'{score} => {result}')

여기서 순서가 중요하다는 걸 새삼 느꼈다. >= 90을 제일 먼저 체크해야지, >= 60부터 체크하면 90점도 D로 잡혀버린다. 위에서 아래로 조건을 하나씩 “먼저 걸리는 것”이 적용된다는 걸 명심해야 할 것 같다.

조건을 여러 개 조합하기, and / or 활용

세 정수 중 최솟값을 구하는 문제를 풀면서 and를 조건 안에서 조합하는 연습을 해봤다.

if num1 < num2 and num1 < num3:
    minNum = num1
elif num2 < num3:
    minNum = num2
else:
    minNum = num3

가위바위보 승패 판정은 조건이 꽤 복잡해서, 줄바꿈(\)을 써서 조건식을 여러 줄로 나눠 썼다.

hong = input('홍길동 입력: ')
lee = input('이몽룡 입력: ')

if hong == '가위' and lee == '보' or \
   hong == '바위' and lee == '가위' or \
   hong == '보' and lee == '바위':
    result = '홍길동이 이겼습니다'
elif hong == lee:
    result = '비겼습니다'
else:
    result = '이몽룡이 이겼습니다'

and가 or보다 우선순위가 높다는 걸 지난 글(연산자 우선순위)에서 정리해뒀던 게 여기서 바로 도움이 됐다. A and B or C and D는 (A and B) or (C and D)로 묶여서 계산된다.

문자열도 부등호로 비교할 수 있다

이건 신기했던 부분인데, 문자열끼리도 <, <= 같은 비교가 된다. (문자의 유니코드 코드 포인트 순서로 비교한다. 그래서 대문자가 소문자보다 앞이라 'Z' < 'a'도 True)

1
2
3

result = 'C'
if 'A' <= result <= 'D' or result == 'F':
    ...

이렇게 'A' <= result <= 'D'처럼 범위를 한 번에 쓸 수 있다는 것도 파이썬만의 특징이라고 한다. (다른 언어는 보통 'A' <= result and result <= 'D'로 풀어써야 함)

삼항연산자, 한 줄 if문

if ~ else를 한 줄로 줄이는 문법이다.

1
2
3
4
5
6
7
8

# 원래 방식
if score >= 60:
    result = '합격'
else:
    result = '불합격'

# 삼항연산자
result = '합격' if score >= 60 else '불합격'

짧은 조건에는 이게 훨씬 간결해서, 앞으로는 값 하나 정하는 정도의 조건문은 이 방식으로 많이 쓸 것 같다.

정리하다 보니 오늘 실수한 부분들이 눈에 띈다. if ~ else만 쓰면 그 사이값(0 같은)을 놓치기 쉬워서 조건 구간이 셋 이상이면 처음부터 elif를 쓰는 습관을 들여야겠고, elif 체인은 순서가 결과를 바꾸니 큰 범위나 좁은 조건부터 먼저 체크해야 한다는 것도 다시 새겼다. 문자열도 유니코드 코드 순서로 부등호 비교가 된다는 건 오늘 처음 안 사실.

  2. 세 변의 길이를 정수로 입력받아서, 삼각형을 만들 수 없으면 “삼각형 불가”를, 만들 수 있으면 “정삼각형” / “이등변삼각형” / “일반 삼각형” 중 하나를 출력하는 코드를 짜보시오. (힌트: 어느 변이든 나머지 두 변의 합보다 짧아야 삼각형이 된다. elif로 판정할 때 어떤 조건을 먼저 체크해야 할지도 생각해볼 것)

  3. 메뉴 번호(1: cm→inch, 2: kg→lb, 3: 섭씨→화씨)와 값을 입력받아 변환 결과를 출력하는 코드를 짜보시오. 1~3이 아닌 번호가 들어오면 “없는 메뉴입니다”를 출력할 것. (1inch = 2.54cm, 1kg = 2.2lb, 화씨 = 섭씨 × 9 / 5 + 32)

  4. 한 글자를 입력받아 영어 대문자면 “대문자”, 소문자면 “소문자”, 숫자면 “숫자”, 그 밖이면 “기타”를 출력하는 코드를 짜보시오. 'A' <= ch <= 'Z' 같은 범위 비교를 써볼 것. 숫자인 경우엔 int()로 바꿔서 짝수인지 홀수인지도 삼항연산자 한 줄로 같이 출력해보시오.
