CSV에서 읽은 열은 값이 보이는 모양과 자료형이 다를 수 있다. "6,500원"처럼 숫자에 글자가 섞이면 문자열로 읽혀 계산이 안 되고, 앞뒤 공백이 붙은 매장 이름은 다른 매장으로 세어진다. 자료형을 바꾸고(형 변환), 문자열을 다듬고, 숫자를 구간으로 묶는(범주화) 방법을 정리한다.

예제 데이터는 00편의 cafe 폴더를 쓴다. Python 3.12, pandas 3.0.6에서 실행한 결과다. orders_raw.csv는 5편에서 쓴 주문 원본이다.

menu_df["band"] = pd.cut(menu_df["price"], bins=bins, labels=labels)
menu_df["band_left"] = pd.cut(menu_df["price"], bins=bins, labels=labels, right=False)

척도 맞추기: 정규화와 표준화

단위가 다른 숫자 열(가격, 잔 수)을 비교하거나 한 식에 넣을 때는 범위를 맞춘다. 대표적인 두 방법은 다음과 같다.

방법식결과 범위
최소-최대 정규화 (min-max)(x − 최솟값) / (최댓값 − 최솟값)0~1
표준화 (z-score)(x − 평균) / 표준편차평균 0, 표준편차 1
1
2
3
4
5

p = menu_df.set_index("name")["price"]
scaled = pd.DataFrame({"price": p,
                       "minmax": ((p - p.min()) / (p.max() - p.min())).round(2),
                       "zscore": ((p - p.mean()) / p.std()).round(2)})
print(scaled.iloc[[0, 7, 9]])

가장 싼 버터쿠키가 0, 가장 비싼 치즈케이크가 1이 됐다. z-score는 평균(약 5,136원)보다 비싼 메뉴가 양수, 싼 메뉴가 음수다. pandas의 std()는 표본 표준편차(ddof=1, n−1로 나눔)이고, NumPy의 np.std()는 기본이 ddof=0(n으로 나눔)이라 값이 조금 다르다.
