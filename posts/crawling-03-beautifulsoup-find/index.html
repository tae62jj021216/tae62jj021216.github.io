2편에서 받은 r.text는 긴 문자열일 뿐이다. BeautifulSoup은 이 문자열을 1편의 DOM 같은 나무 구조로 바꿔, 태그 이름·class·id로 원하는 부분을 찾게 해 준다.

설치는 pip install beautifulsoup4(가져올 때 이름은 bs4). 결과는 Python 3.12, beautifulsoup4 4.15에서 확인했다. 앞부분은 아래 메뉴판 HTML로, 끝에서 연습 쇼핑몰 페이지에 적용한다.

방법결과
.text안쪽 글자를 모두 이어 붙인다. 공백·줄바꿈도 그대로
.get_text(strip=True)조각마다 앞뒤 공백을 없애고 붙인다
.get_text(" ", strip=True)조각 사이에 구분자(여기서는 공백)를 넣는다
.string안쪽이 글자 하나뿐일 때만 그 글자. 자식 태그가 여럿이면 None

li에는 a와 span 두 덩어리가 있어서 .string이 None이다. strip=True는 조각 사이 공백까지 없애 아메리카노4,500원처럼 붙어 버리므로, 조각이 여럿이면 구분자를 함께 준다.

  • 속성은 딕셔너리처럼 tag["이름"] 또는 tag.get("이름")으로 꺼낸다. 없는 속성이면 []는 KeyError, get은 None이다.

이동뜻
.parent / .parents바로 위 태그 / 위로 끝까지
.find_parent("div")위로 올라가며 처음 만나는 div
.children / .contents바로 아래 자식들 (글자 조각 포함)
.next_sibling / .previous_sibling바로 옆 노드 (글자 조각일 수 있음)
.find_next_sibling("li")옆으로 가며 처음 만나는 li
.find_next("span")문서 순서로 뒤에서 처음 만나는 span (형제가 아니어도 됨)

주의할 점: .next_sibling은 다음 태그가 아니라 다음 노드다. 태그 사이에 줄바꿈이 있으면 '\n'이 나온다. 다음 태그가 필요하면 find_next_sibling()을 쓴다.

h2의 다음 형제 ul을 찾은 예처럼, class나 id가 없는 태그는 이웃한 제목 태그에서 출발해 옮겨 가는 방법이 쓸모 있다.

  1. 품절(soldout)인 메뉴의 이름을 출력하는 코드를 쓰시오.
