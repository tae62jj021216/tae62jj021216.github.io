7편에서는 time.sleep과 implicitly_wait로 기다렸다. 이 글에서는 “무엇이 될 때까지” 기다리는 명시적 대기를 익히고, 연습 페이지 두 곳에 적용한다.

  • 고객 리뷰: 1초 뒤에 리뷰 10개가 그려지고, 바닥까지 스크롤하면 10개씩 더 붙는다(전체 50개).
  • 매장 찾기: 시·도를 고르면 구·군 목록이 채워지고, 조회를 누르면 결과 표가 새 표로 바뀐다. CSV 저장 버튼이 있다.

7편의 driver, By를 이어서 쓴다. 결과는 Python 3.12, Selenium 4.50, Chrome에서 확인했다.

자주 쓰는 조건이다. 찾는 위치는 (By.ID, "x")처럼 튜플 하나로 넘긴다.

조건 (EC.)기다리는 것
presence_of_element_located(loc)요소가 DOM에 생김 (안 보여도 됨)
visibility_of_element_located(loc)요소가 화면에 보임
element_to_be_clickable(loc)보이고 클릭할 수 있음
text_to_be_present_in_element(loc, "글자")요소에 그 글자가 나타남
staleness_of(element)갖고 있던 요소가 DOM에서 사라짐

조건 자리에 함수를 직접 넣어도 된다. driver를 받아 참(또는 값)을 돌려주면 된다. 아래 매장 찾기에서 쓴다.

주의할 점: implicitly_wait와 WebDriverWait를 함께 쓰면 두 대기 시간이 겹쳐 예상보다 오래 기다릴 수 있다. Selenium 문서도 섞어 쓰지 말라고 권한다. 이 글처럼 명시적 대기를 쓸 때는 암묵적 대기를 0(기본값)으로 둔다.

import time

last = driver.execute_script("return document.body.scrollHeight")
rounds = 0
while True:
    driver.execute_script("window.scrollTo(0, document.body.scrollHeight);")
    time.sleep(1.5)                          # 새 리뷰가 그려질 시간
    new = driver.execute_script("return document.body.scrollHeight")
    rounds += 1
    if new == last:                          # 더 늘지 않으면 끝
        break
    last = new
print(rounds, len(driver.find_elements(By.CSS_SELECTOR, ".review-item")), driver.find_element(By.ID, "status").text)

execute_script는 브라우저에서 자바스크립트를 실행하고 return 값을 파이썬으로 돌려준다. 4번 스크롤로 40개가 더 붙어 50개가 되었고, 5번째에는 높이가 그대로라 멈췄다.

가상카페 종로구 1호점 서울특별시 종로구 연습로 13 27 N

이 페이지는 조회할 때 표를 고치는 것이 아니라 새 표로 갈아 끼운다. 미리 찾아 둔 table은 이제 DOM에 없는 옛 요소를 가리키므로, 읽으려 하면 “상했다(stale)”는 예외가 난다. 화면이 바뀐 뒤에는 요소를 다시 찾아야 한다.

이 성질을 거꾸로 이용하면 “결과가 바뀔 때까지” 기다릴 수 있다. 옛 표를 잡아 두고, 그것이 사라질 때까지(staleness_of) 기다리면 된다.

all_rows = []
for gu in gus:
    Select(driver.find_element(By.ID, "gugun")).select_by_visible_text(gu)
    old = driver.find_element(By.ID, "store-table")
    driver.find_element(By.ID, "search-btn").click()
    wait.until(EC.staleness_of(old))                 # 옛 표가 사라질 때까지

    soup = BeautifulSoup(driver.page_source, "html.parser")
    for tr in soup.select("#store-table tbody tr"):
        all_rows.append({"gugun": gu,
                         "name": tr.select_one(".store-name").text,
                         "seats": int(tr.select_one(".seats").text),
                         "drive_thru": tr.select_one(".dt").text})
    print(gu, driver.find_element(By.ID, "result-count").text)

st = pd.DataFrame(all_rows)
print(st.shape)
print(st.groupby("gugun")["seats"].sum().to_dict())

정답과 해설
  1. TimeoutException이 난다.
  2. 스크롤한 뒤 페이지 높이(scrollHeight)가 직전과 같으면 멈춘다. 새 내용이 그려지기 전에 높이를 다시 재면(대기가 짧으면) 아직 안 늘어서 일찍 멈춘다.
  3. 첫 조회 뒤 표가 새 표로 바뀌어 table은 옛 요소가 된다. 두 번째 반복부터 staleness_of(table)은 이미 사라진 요소를 보고 바로(실제로 0.01초) 통과해, 새 결과가 그려지기 전에 이전 구의 결과를 읽었다. 반복문 안에서 클릭 직전에 table = driver.find_element(By.ID, "store-table")로 다시 찾는다. 이 페이지의 gugun은 바뀌지 않지만, 화면이 바뀌는 페이지라면 Select(...)도 반복마다 다시 만든다.
