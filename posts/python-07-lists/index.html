대입, 얕은 복사, 깊은 복사, 오늘 제일 조심해야 했던 부분

1
2
3
4
5

names = ['김', '이', '홍']
new_names = names          # 복사 아님! 같은 리스트에 이름표만 하나 더 붙인 것

names[1] = '박'
print(new_names)           # ['김', '박', '홍'] <- new_names도 같이 바뀜!

new_names = names는 복사가 아니라 같은 리스트를 가리키는 이름표를 하나 더 만드는 것이었다. 리스트는 하나고 이름만 두 개라서, 한쪽에서 바꾸면 다른 쪽에서도 바뀐 게 보인다. 따로 된 리스트가 필요하면 list(), names[:], names.copy() 중 하나로 복사해야 하는데, 이게 얕은 복사(shallow copy)다.

1
2
3
4

new_names2 = list(names)   # 얕은 복사: 새 리스트를 만든다 (names[:], names.copy()도 같음)
names[-1] = '최'
print(names)               # ['김', '박', '최']
print(new_names2)          # ['김', '박', '홍'] <- 영향 안 받음

여기서 완전히 독립된 것처럼 보이는 건 사실 요소가 문자열이라서다. 얕은 복사는 바깥 리스트만 새로 만들고, 안에 든 요소들은 원본이랑 같은 걸 그대로 같이 가리킨다. 문자열은 어차피 수정이 안 되니까(immutable) 티가 안 나는 거고, 리스트 안에 리스트가 들어 있으면 얘기가 달라진다.

1
2
3
4
5
6
7

import copy

groups = [['김', '이'], ['홍']]
shallow = list(groups)          # 얕은 복사: 안쪽 리스트는 원본과 공유
deep = copy.deepcopy(groups)    # 깊은 복사: 안쪽 리스트까지 전부 새로 만듦

groups[0][1] = '박'
print(shallow)   # [['김', '박'], ['홍']] <- 안쪽 리스트가 같이 바뀜!
print(deep)      # [['김', '이'], ['홍']] <- 영향 안 받음

정리하면 대입(=)은 같은 리스트를 같이 가리키는 것, list()·copy()·[:]는 겉 리스트만 새로 만드는 얕은 복사, 중첩 리스트의 안쪽까지 완전히 떼어내려면 copy.deepcopy()로 깊은 복사를 해야 한다. 여기서 예전 글의 “변수는 값을 담는 상자가 아니라 이름표”라는 개념이 그대로 이어지는구나 싶었다.

요소 추가, append, insert, extend

1
2
3
4

fruits = ['apple', 'banana']
fruits.append('mango')            # 맨 뒤에 하나 추가
fruits.insert(2, 'coconut')       # 특정 위치에 삽입
fruits.extend(['cacao', 'berry']) # 다른 리스트를 풀어서 이어붙임

append(['a','b'])는 리스트 자체가 하나의 원소로 통째로 들어가고, extend(['a','b'])는 안의 요소들이 각각 풀려서 들어간다는 차이가 있다. 처음에 이 둘을 헷갈려서 결과가 이상하게 나온 적이 있다.

fruits.remove('apple')   # 값으로 삭제 (처음 하나만)
sel = fruits.pop()       # 마지막 요소를 "꺼내면서" 삭제 -> 'berry'
sel2 = fruits.pop(1)     # 인덱스로 꺼내면서 삭제 -> 'coconut'
print(fruits)            # ['banana', 'mango', 'cacao']

nums = [10, 20, 30, 40, 50]
del nums[1]              # 인덱스로 그냥 삭제 (반환값 없음) -> [10, 30, 40, 50]
del nums[2:]             # 슬라이스로 여러 개 한 번에 삭제 -> [10, 30]

remove()는 값으로, pop()/del은 위치(인덱스)로 접근한다는 걸 기준으로 구분해서 외웠다. 그리고 remove()는 같은 값이 여러 개면 딱 첫 번째 것만 지운다는 것도 주의해야 한다. 전부 지우려면 count()로 개수를 센 다음 그만큼 반복해야 한다.

n = fruits.count('apple')
for i in range(n):
    fruits.remove('apple')

정렬, sort() vs sorted()

1
2
3
4
5

fruits = ['banana', 'apple', 'melon']
fruits.sort()              # 원본을 직접 정렬 (반환값 없음! None)
fruits.sort(reverse=True)  # 내림차순

new_f = sorted(fruits)     # 원본은 그대로, 정렬된 새 리스트를 반환

정렬된 걸 받아두려고 ordered = fruits.sort()처럼 써버리면 ordered에는 정렬된 리스트가 아니라 None이 담긴다. 이게 제일 함정이었다. sort()는 반환값이 없고 원본을 직접 바꾸는 메서드라서, 정렬된 결과를 새 변수에 담고 싶다면 sorted()를 써야 한다.

대소문자가 섞인 문자열을 정렬할 때 key=str.lower를 쓰면 대소문자를 무시하고 정렬할 수 있다는 것도 새로 배웠다.

중첩 for문도 한 줄로 줄일 수 있다.

1

main = ['치킨', '피자', '볶음밥']
side = ['단무지', '피클', '김치']
result = [(m, s) for m in main for s in side]   # 모든 조합

처음엔 문법이 낯설어서 오히려 이해하는 데 시간이 걸렸는데, [식 for 변수 in 대상] 순서로 “for문을 먼저 떠올린 다음 앞으로 뒤집는다”고 생각하니 좀 편해졌다.

정리하면서 헷갈렸던 부분들. 리스트 = 리스트는 복사가 아니라 같은 리스트에 이름표를 하나 더 붙이는 것이고, list()·copy()·[:]는 얕은 복사라서 중첩 리스트의 안쪽까지 떼어내려면 copy.deepcopy()가 필요하다. sort()는 반환값이 None(원본을 직접 바꿈)이고 sorted()는 새 리스트를 반환한다는 차이, 그리고 append()와 extend()가 통째로 넣을지 풀어서 이어붙일지 다르다는 것도 다시 챙겨뒀다.
