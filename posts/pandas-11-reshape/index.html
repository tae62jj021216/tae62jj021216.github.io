같은 판매 기록도 날짜·지점·잔 수를 한 줄에 하나씩 쌓으면 93행이 되고, 지점을 열 이름으로 펼치면 31행이 된다. 값은 그대로 두고 표의 모양만 바꾸는 일을 재구조화(reshape)라고 하며, pandas에서는 pivot·stack·melt 같은 함수가 맡는다.

pivot()의 인자 세 개가 역할을 나눈다. index에 준 열의 값이 행 이름, columns에 준 열의 값이 열 이름, values에 준 열의 값이 칸을 채운다. 열은 이름순(강변점, 공원점, 본점)으로 정렬되고, 왼쪽 위의 store는 열 인덱스의 이름이다. values를 빼면 남은 열(cups, revenue)이 모두 펼쳐져 열 이름이 두 단계(10편의 다중 인덱스)가 된다.

aggfunc="count"로 칸마다 주문 수를 셌고, 주문이 없는 칸은 fill_value=0으로 채웠다. fill_value를 빼면 빈 칸은 NaN이 되고 자료형이 실수로 바뀐다. member_id가 빈칸인 비회원 주문 2건은 행 이름을 정할 수 없어 빠졌다.

SELECT m.name,
       SUM(CASE WHEN o.store = '강변점' THEN oi.qty ELSE 0 END) AS 강변점,
       SUM(CASE WHEN o.store = '공원점' THEN oi.qty ELSE 0 END) AS 공원점,
       SUM(CASE WHEN o.store = '본점'   THEN oi.qty ELSE 0 END) AS 본점,
       SUM(oi.qty) AS 합계
FROM order_item oi
JOIN orders o ON o.order_id = oi.order_id
JOIN menu m   ON m.menu_id = oi.menu_id
GROUP BY m.name WITH ROLLUP;

리스트 원소 수만큼 행이 늘었고, 나머지 열(order_id, menu)은 복사됐다. 인덱스도 원래 값(0, 0, 1, …)이 반복되므로, 새 번호가 필요하면 explode("options", ignore_index=True)를 쓴다. 옵션이 없는 5번 주문(NaN)은 NaN 한 행으로 남고, value_counts()에서는 빠진다.

함수별 방향 정리

함수방향집계같은 칸에 값이 여럿이면
pivot긴 → 넓은없음ValueError
pivot_table긴 → 넓은aggfunc집계해서 하나로
crosstab긴 → 넓은개수(기본)개수로 셈
unstack행 인덱스 → 열없음인덱스가 겹치면 ValueError
stack열 → 행 인덱스없음해당 없음
melt넓은 → 긴없음해당 없음
explode리스트 한 칸 → 여러 행없음해당 없음
